## SECTION 3 - All 7 Features in This Pillar

| Feature (What)                                   | How It Works                                                                                                   | Why It Matters (Problem Solved)                                |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| **Structured data capture & lead qualification** | Conversation extracts key fields (budget, timeline, use case) into a structured record scored against your ICP | Unqualified leads flood the sales pipeline                     |
| **Rule-based lead routing**                      | If/then routing engine assigns each qualified lead to the right rep/team based on configured rules             | Slow manual triage; leads sent to the wrong rep                |
| **Meeting booking with CTAs & calendar links**   | Agent checks rep calendar availability via API and lets the visitor book a slot directly inside the chat       | Missed booking opportunities, scheduling friction              |
| **CRM context attached to routed leads**         | Every routed lead auto-populates with the full conversation transcript and enrichment data in the CRM record   | Reps lack context on inbound leads before first contact        |
| **Ideal Customer Profile (ICP) setting**         | Admin defines firmographic/behavioral criteria that the qualification engine scores every visitor against      | Sales time wasted chasing bad-fit prospects                    |
| **Dynamic flow control**                         | Conversation logic branches in real time based on each visitor response, rather than one fixed script          | Rigid, scripted conversations don't adapt to visitor responses |
| **Real-time data capture**                       | Every field captured mid-conversation is written to the backend instantly, not batched                         | Delayed or lost lead data between visit and follow-up          |

## FAQ

Q: How is the ICP score calculated?
A: Admins define firmographic and behavioral criteria; the qualification engine scores every visitor against those criteria as the conversation happens - see Integration & Administration for configuration.

Q: Does this replace our CRM's lead scoring?
A: It feeds your CRM with a pre-qualified score and full context rather than replacing your CRM's own logic - see /integrations/crm.
