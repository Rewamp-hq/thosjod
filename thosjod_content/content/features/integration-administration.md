## SECTION 1 - The Problem

H2: The gap this closes
Body: Manual CRM entry causes sync errors and duplicate records, and deploying new tools is usually a slow, engineering-heavy project.

## SECTION 2 - The Solution

H2: How Thosjod solves it
Body: Native connectors push and pull CRM records in real time, and a guided, no-code setup wizard configures the agent and knowledge base without engineering involvement.

## SECTION 3 - All 5 Features in This Pillar

| Feature (What)                       | How It Works                                                                                                         | Why It Matters (Problem Solved)                             |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **CRM read/write/sync**              | Native API connectors push new/updated records to HubSpot/Salesforce and pull existing record data back in real time | Manual CRM entry, sync errors, duplicate records            |
| **No-code launch and setup**         | Guided setup wizard configures the agent, knowledge base, and embed script without engineering involvement           | Slow, engineering-heavy deployment of new tools             |
| **Agent configuration**              | Admin panel exposes tone, scope, escalation rules, and knowledge sources as adjustable settings                      | One-size-fits-all agent doesn't match team/brand needs      |
| **CRM-driven enterprise setup**      | Enterprise-tier configuration lets CRM data (not just the website) drive agent behavior and routing                  | Fragmented workflows across large, multi-team organizations |
| **Custom filters for deep insights** | Analytics module lets admins segment and filter conversation/lead data by any captured field                         | Generic reporting can't answer specific business questions  |

## FAQ

Q: Which CRMs are supported?
A: HubSpot and Salesforce natively, with Marketo/LeanData on Enterprise - see /integrations.

Q: Do we need engineering resources to launch?
A: No - the setup wizard is designed for no-code configuration by a marketing or sales admin.
