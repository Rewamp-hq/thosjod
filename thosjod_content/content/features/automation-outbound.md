## SECTION 1 - The Problem

H2: The gap this closes
Body: Sales process execution is inconsistent across reps, and warm leads go cold after the first touch because follow-up doesn't happen reliably.

## SECTION 2 - The Solution

H2: How Thosjod solves it
Body: Admins describe a strategy in natural language; Thosjod compiles it into a playbook that follows up automatically on the visitor's preferred channel, using outreach drafted from their actual on-site activity.

## SECTION 3 - All 6 Features in This Pillar

| Feature (What)                                                | How It Works                                                                                                            | Why It Matters (Problem Solved)                             |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **Tailored AI-driven playbooks**                              | Admin describes the outbound/qualification strategy in natural language; engine compiles it into an executable playbook | Inconsistent sales process execution across reps            |
| **Automated follow-up over socials/email**                    | Playbook triggers a follow-up sequence on the visitor's preferred channel after the first interaction                   | Warm leads go cold after the first touch                    |
| **Personalized outreach from visitor activity**               | Outreach copy is auto-drafted using the specific pages/questions the visitor engaged with                               | Generic, irrelevant outbound messaging                      |
| **Sales playbooks - replicate workflows in natural language** | Same natural-language playbook builder applied specifically to sales sequences                                          | Workflows otherwise require engineering/scripting to set up |
| **Bidirectional social SDR**                                  | Agent can both respond to inbound social messages and initiate outbound social outreach on connected channels           | Missed engagement opportunities on social channels          |
| **Combined Sales & Support playbook**                         | A single agent configuration handles both pre-sale qualification and post-sale support in one thread                    | Disconnected sales/support handling of the same visitor     |

## FAQ

Q: Do we need to write code to build a playbook?
A: No - playbooks are described in natural language and compiled automatically; see Integration & Administration for no-code setup.

Q: Which channels does automated follow-up support?
A: Social and email, on the visitor's preferred channel, per the 'Automated follow-up over socials/email' feature.
