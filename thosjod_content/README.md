# Thosjod Content System

Complete content architecture for the Thosjod marketing site, product IA, and supporting reference databases - built for direct handoff to a frontend build (e.g., Claude Code).

## Start Here

1. Read `00-strategy/PROGRESS.md` - full status, what's done, what still needs real input from you.
2. Read `00-strategy/01-executive-product-understanding.md` through `04-messaging-architecture.md`, in order - the positioning foundation everything else builds on.
3. Read `00-strategy/36-frontend-implementation-map.md` - the actual build guide (templates → components).
4. Build pages from `content/`, following `00-strategy/42-content-file-structure.md` for the folder layout.

## Before Publishing Anything

Check `00-strategy/35-founder-input-required.md` - a prioritized list of what needs real facts, legal review, or a judgment call from you before any given page goes live. Nothing in this system was fabricated (no invented customers, testimonials, pricing, certifications, or competitor weaknesses) - gaps are marked, not filled in with plausible-sounding placeholders.
